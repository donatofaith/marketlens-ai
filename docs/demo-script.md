# MarketLens AI — Hackathon Demo Script

## Target Length

Approximately 2–3 minutes.

---

## 1. Introduction

"Hi, this is MarketLens AI, an AI-powered crypto market intelligence agent built for Track A of the Binance Agent OS Mini Hackathon.

MarketLens transforms live Binance market data into structured and explainable market research."

---

## 2. Show the Dashboard

"The dashboard provides a live snapshot of BTC, ETH and BNB market conditions using Binance market data."

Show the three live market cards.

---

## 3. Demonstrate Single-Asset Analysis

Enter:

`Analyze BTCUSDT`

Click **Analyze**.

"The agent understands the request, retrieves the relevant market information, analyzes the data, and generates structured intelligence."

Show the workflow completing:

1. Understand Request
2. Retrieve Market Data
3. Analyze
4. Generate Intelligence

Then show the BTC Intelligence Report.

"MarketLens examines 24-hour momentum, recent hourly candle structure, volume activity and the asset's position within its 24-hour range."

---

## 4. Demonstrate Multi-Asset Comparison

Enter:

`Compare BTC, ETH & BNB`

Click **Analyze**.

"MarketLens can also compare multiple assets to identify relative strength, market activity and recent short-term structure."

Show the generated comparison report.

---

## 5. Demonstrate Morning Market Brief

Enter:

`Morning market brief`

Click **Analyze**.

"The Morning Brief summarizes overall market breadth and identifies the strongest and weakest relative performers from the current data."

Show the report.

---

## 6. Show Binance Agent OS / MCP

Switch briefly to Visual Studio Code.

Show `.vscode/mcp.json` with the Binance Agent OS MCP endpoint configured.

Then show the connected Binance MCP server and its available tools.

If possible, show the previous successful BTCUSDT MCP tool result.

Say:

"MarketLens was built and verified with Binance Agent OS through its MCP integration. The authenticated Binance MCP server exposes Binance capabilities directly to an agent environment."

---

## 7. Explain Safety

"MarketLens is intentionally designed as a research agent. It does not execute trades or provide buy and sell recommendations. Reports describe observed market conditions and include risks and limitations."

---

## 8. Closing

"MarketLens turns raw Binance market data into explainable market intelligence.

Built with Binance Agent OS for the Binance Agent OS Mini Hackathon."
